# Task Management System - Human Specification

I need a web application that helps teams manage their tasks and projects. Here's what I'm thinking:

## What I Want
I want users to be able to create accounts, log in, and manage their personal and team tasks. They should be able to create projects, add tasks to those projects, assign tasks to team members, and track progress.

## Key Features
- User registration and login (email/password)
- Personal dashboard showing my tasks and projects
- Create and manage projects 
- Add tasks to projects with due dates, descriptions, priorities
- Assign tasks to team members
- Mark tasks as complete
- See project progress and team workload
- Get notifications for important deadlines
- Search and filter tasks

## Technical Preferences  
I'd prefer using modern web technologies. Something like React for the frontend would be good. For the backend, maybe Node.js with Express. Use a database that can handle relationships well - probably PostgreSQL.

## Important Requirements
- Should work on both desktop and mobile
- Need good performance - pages should load quickly
- Security is important - user data needs to be protected
- Should be easy to use and intuitive
- Want real-time updates when team members make changes

## Success Criteria
The system is successful if:
- Teams can effectively track and manage their work
- Users find it easy and intuitive to use
- Performance is good (under 2 seconds for most operations)
- No data loss or security issues
- Team productivity improves

I'd like this completed in about 2-3 weeks if possible. Let me know if you need any clarification!
