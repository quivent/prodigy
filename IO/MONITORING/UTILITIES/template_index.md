## Time Tracking Standards

### Execution Time Categories
- **Quick Operations:** <3 minutes (simple updates, minor fixes)
- **Standard Operations:** 3-8 minutes (algorithm iterations, process improvements)  
- **Complex Operations:** 8-15 minutes (major feature development, system overhauls)
- **Extended Operations:** >15 minutes (research investigations, comprehensive analysis)

### Rate of Optimization Calculation
```
Performance Improvement Rate = (Final Metric - Initial Metric) / Number of Iterations
Time Investment Growth = Average Duration Increase per Iteration
Efficiency Ratio = Performance Improvement / Time Investment
Optimization Velocity = Rate of improvement change over time
```

### Template Usage Protocol
1. **Task Classification:** Identify task type from criteria above
2. **Template Selection:** Choose appropriate template from index
3. **Time Tracking:** Record start time and estimate complexity
4. **Execution Monitoring:** Provide status updates every 2-3 major operations
5. **Results Documentation:** Complete template with actual duration and metrics
6. **Template Evolution:** Update template based on usage patterns and feedback
