## 📖 Usage

### Installation
```bash
# Build the CLI
CGO_ENABLED=0 go build -ldflags="-s -w" -o prodigy

# Install globally
cp prodigy ~/.local/bin/prodigy
```

### Basic Commands
```bash
# Create a new agent
prodigy create:agent AgentName

# Initialize intelligence systems
prodigy wake-up

# Execute learning protocols
prodigy learn --domain [domain]

# Research investigations
prodigy research --topic [topic]

# Memory operations
prodigy memory --store [experience]
```

### Configuration
- **Agent Templates**: Pre-configured specialist roles
- **Learning Parameters**: Customizable learning rates and strategies
- **Memory Settings**: Storage organization and retrieval preferences
- **Research Protocols**: Investigation methodology configuration
